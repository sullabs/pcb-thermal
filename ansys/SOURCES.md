# Source of truth

Every piece of information has exactly one owner. Everyone else reads it or derives it, and never types it again.
If two places disagree, the owner wins and the other one is regenerated.

Owners:
- **EDB** = `<board>.aedb`, exported from Altium (File > Export > Ansys EDB). Read only for us.
- **project.json** = typed by the user (page or editor). The only file with user decisions.
- **parts.json** = datasheet values per part number, reused by every board. Typed once.
- **AEDT** = the Icepak project. Fully generated by the setup script; never edited by hand.
- **results.json** = written by the script only (empty until solving is added).

| Information | Owner | Read by | Notes |
|---|---|---|---|
| Board outline, thickness | EDB | script, page | |
| Stackup: layers, copper thickness, dielectric | EDB | script, page | Material k comes from the AEDT library by name |
| Vias, traces, copper coverage per layer | EDB | script | Icepak derives effective PCB k from these |
| Component list: RefDes, part number, package, placement, height | EDB | script, page | If the export lacks a part number, add a mapping in `project.json` `partMap` |
| Component power (W) | project.json `power` | script, page | Per RefDes. Never read from EDB |
| Rjc, Rjb, Tj max, package size | parts.json | script, page | Keyed by part number; project.json `partOverrides` wins for one board |
| Materials (k, density, cp) | AEDT library | script | Overrides only in project.json `materials` |
| Ambient temperature, altitude, orientation, air speed | project.json `environment` | script, page | |
| Emissivity per surface group | project.json `surfaces` | script | |
| Heat sink / spreader / TIM | project.json `cooling` | script | |
| Mesh level, convergence limits | project.json `solver` | script | Defaults live in the script, written back to project.json once |
| Icepak objects, boundaries, setup | AEDT | nobody | Derived. Script rebuilds or patches it from the rows above |
| Last applied state (hash per section) | `applied.json` | script | Script-owned; lets a re-run patch only what changed |
| Board summary shown on the page (components, stackup) | `board.json` | page | Derived snapshot of the EDB, written by the script |
| Setup check result (what is missing or odd) | `checks.json` | page | Script-owned; the page only displays it |
| Temperatures and verdicts | results.json | page | Not produced yet |

Rules:
1. The page writes `project.json` only. The script writes `board.json`, `checks.json`, `applied.json`, `results.json`
   and the AEDT project only.
2. A value is never copied into a second file. If something needs it, it reads the owner, or the script puts a
   derived copy in `board.json` with the owner named in a `source` field.
3. Every number the script sends to AEDT is logged with its owner, so a wrong value can be traced in one step.
